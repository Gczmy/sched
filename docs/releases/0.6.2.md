# sched 0.6.2 候选说明

0.6.2 扩展 native 与候选包的构建矩阵：CPython 3.10/3.12/3.14，分别在
Ubuntu 22.04/24.04 构建，记录 glibc 2.35/2.39。新增 CPython 3.12 的两种 libc
组合独立完成 native 回归、安装与候选包校验，不能用其他 ABI 的结果代替。

发布准备要求所选完整 main commit 的 18 项 CI 全部成功，并核验六份同次构建的
原始 ZIP。资产包含六份 ZIP、来源证据、发布说明和总校验和，共九项；保存各包自身的
manifest 和原始字节，不跨包替换默认 wheel。native 须匹配解释器 ABI 与记录的 libc，
不声明 manylinux 可移植性。默认 wheel 继续支持 Python >= 3.10，运行时零第三方依赖。

writer schema 保持 25，完整只读范围为 1–25；运行时调度、租约守护、CPU affinity
和未知执行禁止重放的合同不变。安装、维护及 schema 回退边界见
[execution-rollout](../execution-rollout.md) 与 [upgrade-snapshot](../upgrade-snapshot.md)。

本页随版本源码进入候选 ZIP 的 RELEASE_NOTES.md。候选构建和资产准备不代表正式
Release/tag 已发布或目标已升级；正式发布与生产切换分别记录。已发布 0.6.1 的
原标签和七项原始资产保留。
