固定来源为 `7db51e6728bc493776136c8b3c0ec75cf45f88a1`。

native 覆盖 CPython 3.10/3.14、Linux x86_64、glibc 2.35/2.39；默认 wheel 无第三方运行时依赖。
原始 manifest 保留构建时的候选状态；正式发布事实以 Release/tag 与 release-evidence.json 为准。
发布不代表机器已部署，生产状态仍需通过 CLI 查询。

## 行为

持久实例身份只在 writer 迁移中生成一次。只读 identity/request-status 不创建或迁移状态。
task 与单任务 execution 在同一数据库快照报告实例和项目。
请求可绑定预期实例/项目；原始无新增参数的请求绑定保持不变。
结构化操作事实在输出压缩后保留；旧回执不从文本推断效果。

幂等 submit 使用原始 request ID 与有限规范 JSON。网关保存私有 intent/inbox 文件，
daemon 原子发布批次与不可变接受/拒绝回执。重放返回原 batch ID；未知不重投。
无 request ID 的 submit 保留原语义。详见 [集成合同](../integration-contract.md)。

## 升级边界

默认 wheel 要求 Python >= 3.10，无第三方运行时依赖。native ABI/libc 范围只以最终 CI
manifest 为依据。schema 10 新增身份与结构化回执；完整只读支持 schema 1–10。
0.3.1/更旧程序不能打开新写库。排空后切换独立安装，保留原任务、队列、未知尝试和恢复点；
不能删除回执或重新生成实例身份来回退。维护过程见 [execution-rollout.md](../execution-rollout.md)。

lab-ledger 与 dsh 按各自仓库独立维护，不成为 sched 的运行时依赖。
W&B 联网、台账权威切换和科研任务调度不属于本版本的自动激活行为。
