# sched 0.2.2 Release 说明

本版本于 2026-10-01 正式发布为
[v0.2.2](https://github.com/Gczmy/sched/releases/tag/v0.2.2)，来源提交为
`8aa2559dc64e74acd2cec6bcb2f5481d1d9fbc1d`。
[完整 CI](https://github.com/Gczmy/sched/actions/runs/36881160410) 的 14 项检查全部通过；
七个 Release 资产的公开下载字节已与验收产物逐一核对。生产部署独立安排。
各包哈希、ABI、libc 和独立安装证据见包内 manifest 与 `release-evidence.json`。

## 主要变化

- `daemon check --json` 按注册 backend ID 预检 executable 与项目 root，
  检查有界 SHA-256、ELF 标识、读取漂移、普通文件与目录权限，返回稳定错误码。
  检查不创建 attempt 或 child，不代替实际启动时的绑定验证。
- 默认安装与回归扩展至 Python 3.10–3.14。native 安装、回归、真实执行生命周期
  和候选构建覆盖 CPython 3.10/3.14、Ubuntu 22.04/24.04 / Linux x86_64。
  真实 syscall 拒绝验收证明缺失或被拒绝的能力不会被标为 verified。
- 仓库自带发布准备脚本和手动 workflow，从最终 main 的完整成功 CI 下载原始
  四组 ZIP，校验 artifact digest、包内 manifest 和来源，生成总校验和、说明与
  CI 证据。可选择上传绑定一致的 Release 草稿，明确拒绝覆盖已有资产；不会自动发布。

## 安装与兼容性

默认 wheel 要求 Python >= 3.10，运行时无第三方依赖；调度执行要求 Linux/POSIX。
native wheel 覆盖 Linux x86_64、CPython 3.10/3.14 与 glibc 2.35/2.39，
须匹配解释器 ABI、平台和包内 libc，不声明 manylinux 通用兼容。
写库仍为 schema 7，只读 schema 1–7；现有状态、FD4 identity 与未知结果禁止重放
契约保持不变。输入文件、ELF 实际加载和后续启动能力仍在实际启动时验证。

## 发布、维护与回退

四份 ZIP 保留原始 CI 字节，另有 `release-evidence.json`、`RELEASE_NOTES.md` 和
`SHA256SUMS`；下载后先核对总校验和，再按 ABI/libc 选择包。
资产中的候选标记与说明记录构建、准备时状态，发布时未改写 manifest 或哈希；
正式发布事实由 Release/tag 记录。
维护、schema 回退和未解决 owner 的保留要求见
[execution-rollout.md](../execution-rollout.md)。生产切换独立安排。
