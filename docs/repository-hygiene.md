# 仓库信息边界

提交前使用 `python3 scripts/check_repository.py --staged`；全量检查、例外格式、
提交钩子和公共 CI 见[开发与提交检查](../CONTRIBUTING.md)。

公开源码、文档和测试只保留通用示例。个人家目录、实际计算节点、screen 会话、
租约、实验批次名称、生产状态快照、部署回执和一次性迁移脚本应保存在仓库外。
需要本地笔记时使用被忽略的 `.local/`，不要将真实 profile 或配置覆盖到已跟踪示例。

示例路径使用 `/srv/projects/example`、`/home/user` 或显式占位符，域名使用
`example.invalid`，任务与项目用 `example`、`task-1` 等通用名称。公共包名、
协议字段和上游署名属于接口或来源信息，不能为脱敏随意改名。

忽略规则只防止新文件被意外加入版本控制，不会清除已经提交的内容。删除当前文件
也不会从旧提交、标签、PR 差异、克隆或缓存中删除信息。历史清理必须另行规划
受影响引用、协作者同步和恢复方式，不能将普通清理提交描述为历史已净化。

实验 native 协议的部署绑定已移到摘要固定的管理员私有配置，见
[native-deployment.md](native-deployment.md)。公开源码不再提供真实部署默认值；
旧冻结合同和向量作为私有兼容性测试输入保留，不复制到公共测试数据。
